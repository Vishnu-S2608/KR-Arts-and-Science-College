# KR Arts And Science College - Web Platform

Official modern web platform for **K.R. College of Arts & Science** (Affiliated to Madurai Kamaraj University, Established 2023, Peraiyur, Madurai).

## 🚀 Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
- **Motion & Icons:** Lucide React, Framer Motion

## 📁 Repository Structure
```
KR-Arts-and-Science-College/
├── Kr-Arts and Science/         # Next.js Application Root
│   ├── src/
│   │   ├── app/                 # App Router (Home, Events, Apply, Clubs, Contact, Department)
│   │   ├── components/          # React Components (Hero, Sections, Layout)
│   │   ├── data/                # Department and Placements data
│   │   └── styles/              # Design tokens and custom styles
│   ├── public/                  # Static assets & images
│   ├── package.json
│   └── tsconfig.json
└── README.md
```

## 🛠️ Getting Started

```bash
cd "Kr-Arts and Science"
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

## 📦 Production Build
```bash
cd "Kr-Arts and Science"
npm run build
npm run start
```
